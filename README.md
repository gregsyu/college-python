# Estudos de Python

Repositório de exercícios e projetos desenvolvidos durante os estudos de Python.

## Estrutura

- `exercicios/fundamentos/`: exercícios numerados `ex01.py` a `ex17.py`.
- `exercicios/revisao-1a-etapa/`: primeira lista de revisão.
- `exercicios/revisao-2/`: segunda lista de revisão e material de apoio.
- `exercicios/segundo-periodo/`: exercícios do segundo período.
- `projeto-modulos/`: projeto de cadastro e vendas, dividido entre `main.py`, `menu.py` e `model.py`.

## Como executar

Execute um exercício pelo caminho a partir da raiz do repositório. Por exemplo:

```powershell
python .\exercicios\fundamentos\ex01.py
```

Para iniciar o projeto modular:

```powershell
python .\projeto-modulos\main.py
```

Os exercícios são independentes entre si. Alguns aguardam dados digitados no terminal.
